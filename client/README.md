# threeds-remote (client)

Command-line client for [3ds-remote](https://github.com/carlbastos/3ds-remote). Works on Windows, macOS and Linux with Python 3.8+.

```sh
pipx install "git+https://github.com/carlbastos/3ds-remote#subdirectory=client"
3ds login --host <3DS IP>
3ds status
```

See the [main README](https://github.com/carlbastos/3ds-remote#readme) for every command.
